When asked to rebuild or relaunch QuickPlayer, publish a framework-independent
(self-contained) `win-x64` Release application directly into this directory and
launch this exact executable:

`C:\Users\Jeremy\source\repos\KittyPingu\IStripperQuickPlayer\IstripperQuickPlayer\bin\x64\Release\net10.0-windows\IstripperQuickPlayer.exe`

Do not use the Debug output, installed application, or another publish directory.
